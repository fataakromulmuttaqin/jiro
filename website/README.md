# Jiro Sniper Net — Website

Vite + React 19 + TypeScript + Tailwind v4 SPA. Reads JSON output from
the Python pipeline at build/runtime — **zero backend, $0/month**.

## Architecture

```
React SPA (this dir)
   ↓ reads /data/*.json (static)
public/data/
   ├── manifest.json              ← auto-generated by sync_website_data.py
   ├── sniper_net_<mint8>.json    ← one per analyzed mint
   ├── sniper_net_batch.json
   ├── watchlist.json
   └── watchlist_diff.json
```

## Develop

```bash
cd ~/ruangkerja/jiro/website
npm install
npm run dev    # → http://localhost:5173
```

## Build

```bash
npm run build  # → dist/
```

## Deploy

```bash
# First time: link to your Vercel account
vercel link

# Then:
vercel --prod --yes
```

## Pages

| Path | Purpose |
|---|---|
| `/` | Overview — summary cards + tracked mints table |
| `/wallets` | Cross-mint wallet leaderboard (PnL, W/L) |
| `/cabals` | All detected CABAL + SUSPECT_CLUSTER groups |
| `/watchlist` | Current smart money watchlist + diff log |
| `/behavior` | Archetype distribution + per-wallet tags |
| `/mint/:mintShort` | Single-mint deep dive |

## Data flow

1. Python pipeline runs `run_sniper_net.py <MINTS>` → emits JSON to
   `~/ruangkerja/jiro/cache/`.
2. `sync_website_data.py` copies + generates `manifest.json` into
   `website/public/data/`.
3. Vercel auto-deploys from GitHub (or run `vercel --prod --yes`
   manually after each sync).

## Cost

**$0/month.** Static site on Vercel hobby tier, no API keys.
All on-chain data reconstructed from free Helius RPC.

## Limitations

- All data is read at page-load. No live streaming.
- For cabal detection quality, the site needs cross-mint aggregation
  (P5 work). Each mint is analyzed independently right now.
