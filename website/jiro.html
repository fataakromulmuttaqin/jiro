Solana · scaffold open-source

Temukan momentum sebelum crypto twitter sadar.

Jiro memantau apa yang mulai viral di kalangan normies di X, mencari celah sebelum ditokenkan CT, lalu menyekor entry dengan sinyal narasi dan on-chain. Exit dijaga oleh trailing stop, partial take-profit, dan deteksi dump on-chain. DRY_RUN aktif secara default.

Alur kerja

Dari scan sampai posisi ditutup, lima langkah.

Setiap loop, Jiro menjalankan urutan yang sama: cari narasi, cek apakah ada gap, beri skor, buka posisi bila lolos filter, lalu pantau terus sampai salah satu sinyal keluar terpicu.

01

Scan narasi

Grok memindai X untuk narasi viral baru yang masih di luar radar crypto twitter.

02

Cek gap on-chain

rpc_client & onchain_analyzer mengecek apakah narasi itu sudah ditokenkan, dan seberapa sehat likuiditasnya.

03

Skor entry

Kekuatan narasi digabung dengan momentum on-chain jadi satu entry_score, dengan filter keras untuk likuiditas dan price impact.

04

Buka posisi

Bila skor lolos ambang minimum, trading.py mengeksekusi swap lewat Jupiter dengan ukuran posisi tetap.

05

Pantau & keluar

Posisi dicek tiap monitor_interval_seconds terhadap enam sinyal exit, sampai salah satunya terpicu.

Yang dikerjakan tiap modul

Lima file, satu tanggung jawab masing-masing.

narrative.py Grok

Memindai X untuk narasi off-crypto yang baru viral, dan mengecek ulang kesehatan narasi (accelerating / peaking / declining / dead) untuk posisi yang sedang terbuka.

onchain_analyzer.py Solana RPC + Dexscreener

Mendeteksi whale dump, penarikan likuiditas, perubahan rasio buy/sell, dan penurunan harga cepat berbasis kecepatan (velocity).

trading.py Jupiter

Eksekusi swap, penghitungan entry score, pelacakan posisi, trailing stop, partial take-profit, dan kill switch kerugian harian.

safety.py pre-check

Sellability pre-check lewat quote round-trip SOL → token → SOL sebelum membeli, untuk menyaring pola honeypot yang paling umum.

gap_finder_bot.py orkestrator

Menjalankan seluruh alur di atas dalam satu loop: scan → cek gap → skor entry → buka posisi (opsional) → recheck narasi berkala → monitor (opsional).

Manajemen exit

Enam sinyal keluar, dicek dalam urutan prioritas tetap.

Sinyal dengan prioritas lebih tinggi bisa membatalkan sinyal di bawahnya. Stop-loss selalu aktif sebagai lantai keamanan, apa pun yang terjadi di atasnya.

Sinyal dump on-chain

Penurunan saldo whale, penarikan likuiditas, perubahan tekanan jual, atau dump kecepatan harga. Satu saja terpicu, posisi langsung ditutup — mengesampingkan TP/SL.

Prioritas tertinggi

Narasi melemah

Bila recheck Grok menandai narasi declining/dead saat posisi masih untung, ditutup untuk mengunci gain, tanpa menunggu harga menyusul turun.

Trailing stop

Naik mengikuti puncak harga, keluar saat harga mundur melewati jarak trail. Sengaja mengesampingkan take-profit tetap agar posisi menang tidak terpotong terlalu awal.

Partial take-profit ladder

Menjual sebagian posisi (dihitung dari ukuran awal) di tiap level profit yang ditentukan; sisanya tetap berjalan di bawah trailing stop.

Stop-loss

Lantai keras, selalu aktif terlepas dari sinyal lain di atas.

Selalu aktif

Take-profit tetap

Hanya dipakai sebagai mekanisme exit bila trailing_stop_enabled diset false.

config.json

Semua angka trading diatur di satu file.

Tidak perlu ubah kode — bot membaca ulang config.json di setiap loop, jadi perubahan langsung berlaku pada siklus berikutnya.

config.json
{
  "trading": {
    "position_size_usd": 50,
    "max_open_positions": 3,
    "trailing_stop_enabled": true,
    "trailing_stop_activate_pct": 30,   // aktif setelah +30%
    "trailing_stop_distance_pct": 15,   // jarak 15% dari puncak
    "partial_take_profit": [
      { "at_pct": 40,  "sell_pct": 50 },
      { "at_pct": 100, "sell_pct": 50 }
    ],
    "take_profit_pct": 60,
    "stop_loss_pct": 25,               // lantai keras
    "max_daily_loss_usd": 50            // kill switch harian
  },
  "entry_filters": {
    "min_entry_score": 4.0,
    "min_liquidity_usd": 2000,
    "max_liquidity_usd": 80000          // di atas ini, gap dianggap sudah lewat
  }
}

Mekanisme keamanan

Yang sudah dijaga bot ini.

  • ✓Dry-run secara default — tidak ada transaksi nyata sampai AUTO_TRADE_ENABLED dan DRY_RUN sengaja diaktifkan.
  • ✓Pre-check sellability — quote round-trip sebelum beli untuk menyaring pool yang tidak bisa dijual balik.
  • ✓Ukuran posisi tetap — tidak ada martingale, tidak ada scale-in ke posisi rugi.
  • ✓Kill switch harian — berhenti membuka posisi baru begitu kerugian terealisasi menyentuh batas harian.
  • ✓TP & SL di setiap posisi — dihitung saat entry, dicek tiap siklus.

Yang tidak bisa dilindungi bot ini

Batasan yang jujur diakui.

  • !Rug yang selesai lebih cepat dari konfirmasi transaksi exit.
  • !Slippage ekstrem di pool yang sangat tidak likuid, walau limit sudah diset.
  • !Kongesti RPC yang menunda sell melewati waktu exit yang diinginkan.
  • !Honeypot di level kontrak yang memblokir jual tanpa terlihat di quote.
  • !Bacaan Grok soal "apa yang viral" bisa salah atau usang — ini sinyal, bukan kepastian.

Menjalankan Jiro

Mulai dari mode riset dulu, baru pertimbangkan auto-trade.

1

Install dependency

Butuh Python 3. Tidak ada instalasi tambahan di luar tiga package ini.

pip install requests solders base58 --break-system-packages
2

Mode riset / alert saja — aman, tanpa wallet

Cara paling aman untuk mulai: hanya scan dan kirim notifikasi, tanpa transaksi sama sekali.

export XAI_API_KEY=your_xai_key
export TELEGRAM_BOT_TOKEN=xxx        // opsional
export TELEGRAM_CHAT_ID=xxx          // opsional

python3 gap_finder_bot.py --loop
3

Mode auto-trade — uang sungguhan, risiko sungguhan

Gunakan burner wallet. Biarkan DRY_RUN=true sampai kamu benar-benar memahami perilaku bot dari log.

export SOLANA_PRIVATE_KEY=your_base58_secret_key   // burner wallet
export RPC_URL=https://your-rpc-provider-url
export AUTO_TRADE_ENABLED=true
export DRY_RUN=true

python3 gap_finder_bot.py --loop --with-monitor

Ini bukan produk trading yang sudah diaudit.

Jiro adalah scaffold untuk dikembangkan, diuji, dan diperkuat lagi — bukan produk jadi. Logikanya sudah diuji dengan feed harga tiruan, tapi belum pernah diuji langsung terhadap RPC/Jupiter/Dexscreener sungguhan di kondisi pasar nyata, dan pengujian sebanyak apa pun tidak menggantikan audit sungguhan.

Tidak ada apa pun di halaman ini yang merupakan nasihat keuangan. Gunakan burner wallet, mulai dengan position_size_usd kecil, dan hanya danai dengan jumlah yang kamu siap kehilangan sepenuhnya.
